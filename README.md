# Mini SOC Log Monitor
A Python-based Mini Security Operations Center (SOC) log monitoring and alert detection system.

## Overview
This project simulates a basic SOC workflow by processing authentication logs, detecting suspicious login activity using rule-based detection techniques, generating security alerts, storing alerts in JSON format, and producing an alert summary.
The project is designed as a practical cybersecurity learning project focused on security monitoring, authentication analysis, and alert handling.

## Features
- Authentication log parsing
- Brute-force login detection
- Detection of successful logins following repeated failures
- Detection of successful logins for unknown users
- Security alert severity classification
- Human-readable SOC-style alert output
- JSON-based alert storage
- Alert summaries by severity and alert type

## Detection Rules
### 1. Brute Force Detection

Detects repeated failed login attempts from the same IP address within a configured time window.

**Default configuration:**
- Threshold: 5 failed attempts
- Time window: 60 seconds
- Severity: HIGH

### 2. Successful Login After Repeated Failures

Detects a successful login occurring after multiple failed authentication attempts from the same IP address.

**Default configuration:**
- Threshold: 3 failed attempts
- Time window: 300 seconds
- Severity: HIGH

### 3. Unknown User Login

Detects a successful login attempt for a username that is not present in the configured list of known users.

**Severity:** MEDIUM

## How It Works
The project follows a simple SOC-style processing pipeline:

```text
Authentication Logs
        ↓
    Log Parser
        ↓
  Detection Rules
        ↓
     Alerts
        ↓
 ┌──────┴────────┐
 ↓               ↓
Console        alerts.json
Output             ↓
              Alert Summary
```
log_parser.py reads and parses authentication log entries.
detector.py applies rule-based detection logic.
alerts.py formats detected events as SOC-style alerts.
alert_writer.py stores generated alerts in alerts.json.
alert_summary.py provides statistics about detected alerts.
main.py coordinates the complete workflow.

# Mini-SOC Log Monitor

A Python-based security log monitoring tool that analyses authentication logs, detects suspicious login activity, and generates structured security alerts.

## Features

- **Log parsing:** Extracts timestamps, event types, usernames, and IP addresses from authentication logs.
- **Brute-force detection:** Identifies repeated failed login attempts within a configurable time window.
- **Successful login after failures:** Detects successful authentication following repeated failed login attempts.
- **Unknown-user detection:** Flags login activity involving usernames outside a configured list of known users.
- **Severity classification:** Assigns severity levels to security alerts.
- **Alert summaries:** Summarises detected alerts by severity and alert type.
- **JSON alert output:** Saves generated alerts in JSON format.
- **Input validation:** Handles malformed log entries and invalid fields.
- **Automated tests:** Uses pytest to test parsing, detection rules, and alert output.

## How It Works

1. Reads authentication log entries from the sample log file.
2. Parses each entry into structured data.
3. Runs detection rules against the parsed events.
4. Generates alerts for suspicious authentication activity.
5. Displays alerts and produces a summary.
6. Saves alerts to a JSON file.

## Detection Rules

| Alert Type | Description |
|---|---|
| `BRUTE_FORCE` | Detects repeated failed login attempts from an IP address within a time window. |
| `SUCCESS_AFTER_FAILURES` | Flags a successful login following multiple failed attempts. |
| `UNKNOWN_USER_LOGIN` | Flags login activity involving a username not included in the known-user list. |
